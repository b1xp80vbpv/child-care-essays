# 唐氏结果三项看男女怎么看？是看矫正mom值吗？

> 更新时间：2026-09-16 (UTC+8)

准确的来说B超是可以看男女的，主要还是看男女的生殖特征去辨别的，和唐氏筛查的关系不是很大，因为唐氏筛查是检查18号染色体的三体综合征、13号染色体的三体综合征、21号染色体的三体综合征的情况，其中18号染色体的三体综合征也就是唐氏综合征。实际上唐筛的NT报告是检查胎儿颈项透明层的厚度，一般小于3mm属于正常的，大于3mm就有唐氏综合征胎儿的风险，并且后面做无创DNA或者羊水穿刺都是有必要的，因为这无创DNA和羊水穿刺的检查结果比唐筛要准确很多，当然这两项检查也是可以辨别胎儿性别的，只是在国内不允许非医学需要鉴定胎儿性别。
有个闺蜜和我说唐筛结果中有三个指标是AFP、HCG、UE3，从b-hcg的mom值中可以看出是男生女，当时她就是因为mom值大于1判断的自己怀上了女宝宝，结果后开生出的孩子是女孩，这种说法是真的吗？

我对网上关于mom值看男女的说法也是有所了解，分别是三个方向：

1、mom值小于0.4,有90%的几率是男孩;

2、mom值大于1，有90%的几率是女孩;

3、当mom值介于0.4-1之间，男女的几率是一样的。

唐筛检查的是胎儿颈部透明带

在这个时候我需要告诉你们的是目前在怀孕的时候不管是怀的男宝还是女宝，b-hcg值都会上升，从而对mom值的影响也不是男女性别决定的，因为在女性怀孕之后，能影响mom值的只有怀孕周数、自身体重、女性年龄等情况影响，和胎儿是男是女关系不大。

我今天去做的唐筛，在显示屏上面看到了三条白色痕迹，当时我就问医生这三条白色痕是什么，医生说是胎儿的胸骨，后来我在姐妹群里面问了一下，有姐妹说那是男宝宝的标志，这是这的吗？

我也不清楚你所说的三条白色痕迹是什么，唐筛是检查胎儿颈部，那三条白色痕迹应该是胸部，也可能是和颈部相关的部位，但是关于医院看胎儿性别是违法的，目前在正规医院还没有医院会给没有特殊情况的孕妈们检查胎儿性别，而你姐妹们的说法，你可以当做是娱乐，不要抱太大希望，其实孩子是男是女都没有多大影响，只有母子平安就好。

我身边很多姐妹都说唐筛三项看男女很准，基本就两种情况，说准确率有95%，基本情况如下：

怀男孩情况：

1、HCG0.5，AFP1

2、0.5HCG1，AFP1

3、HCG1，AFP1

怀女孩的情况：

1、HCG0.5，AFP1

2、0.5HCG1，AFP1

3、HCG1，AFP1

而我的情况是HCG0.42,AFP值0.93，按照这种计算公式，那我就是怀的女孩，这真的准确吗?

这个结果是不能看男女的，唐筛只是看唐氏综合征的风险，如果风险高就需要做羊水穿刺或者无创DNA检查确认，一旦确认是唐氏综合征胎儿医生都是建议终止妊娠的，毕竟生下来唐氏综合征的孩子对家庭的负担也是不小。
